

#### Système de gestion des noms de domaines

**L'icann** est un organisme qui gere la liste des **Top Level Domain (TLD)**
Il existe une TLD par pays.

L'ICANN delegue la gestion de chaque TLD a un organism (registry).

Chaque registry autorise des registrats a vendre des noms de domaine.

Chaque pays possede un TLD qui correspond a son code pays ISO.
On les appelle ccTLD (country-code TLD).

**service TCP/IP** : Permet la correspondance entre un nom de domaine qualifié FQDN (Full Qualified Domain Name) et une adresse IP.
****
**Domaine Inverse** : Resolution d'une adresse IP en nom de domaine avec l'ajout special

#### Serveur cache
